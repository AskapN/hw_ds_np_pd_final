## Инструкция по выполнению проектной работы

### Шаг 1. Подготовка окружения и данных

1. Скачайте архив с данными для проекта [по ссылке](https://u.netology.ru/backend/uploads/lms/content_assets/file/14843/artifacts_csv.zip) и распакуйте его в папку вашего проекта.
2. Убедитесь, что у вас установлен Python, а также библиотеки `pandas`, `streamlit`, `matplotlib`. Если нет, установите их:

```bash
pip install pandas streamlit matplotlib
```

3. Создайте в папке проекта файл `app.py`.

### Шаг 2. Написание кода приложения

Следуйте структуре, описанной ниже. Вы можете использовать свой подход, но результат должен соответствовать техническому заданию.

**1. Импорт библиотек:**

```python
import streamlit as st
import pandas as pd
import matplotlib.pyplot as plt
```

**2. Загрузка данных:**

- Напишите функцию `@st.cache_data`, которая будет загружать три CSV-файла в pandas DataFrame.
- Добавьте заголовок приложения с помощью `st.title()`.

**3. Объединение таблиц:**

- Объедините `orders` с `users` по `user_id`.
- Объедините получившуюся таблицу с `items` по `item_id` (или аналогичному ключу).
- Итоговый DataFrame должен содержать информацию о заказе, пользователе и товаре.

**4. Очистка данных:**

- Проверьте итоговый DataFrame на пропуски (`isnull().sum()`). Примите решение: удалить строки с пропусками или заполнить их (например, неизвестную категорию заполнить как `«Unknown»`).
- Проверьте типы данных. Убедитесь, что колонки с датами имеют тип `datetime`, а числовые колонки (сумма, цена) — `float` или `int`.

**5. Создание дашборда в Streamlit:**

**5.1 Вкладка или блок «Сырые данные»**  
Отобразите итоговый DataFrame с помощью `st.dataframe()` или `st.table()`. Добавьте возможность фильтрации по дате или категории.

**5.2 Вкладка или блок «Ключевые показатели»**  
Рассчитайте и отобразите с помощью `st.metric()`:

- Общее количество заказов
- Общую выручку
- Количество уникальных пользователей
- Средний чек (общая выручка / общее количество заказов)

**5.3 Вкладка или блок «Визуализация»:**

- Топ-10 товаров по выручке  
  Создайте горизонтальную столбчатую диаграмму (bar chart) с помощью `matplotlib` и отобразите её через `st.pyplot()`.

- Выручка по категориям товаров  
  Создайте круговую диаграмму (pie chart) или столбчатую диаграмму, показывающую долю каждой категории в общей выручке.

- Зависимость количества заказов от дня недели  
  Создайте линейный или столбчатый график.

**5.4 Вкладка или блок «Аналитические выводы»:**  
Используйте `st.markdown()` или `st.write()`, чтобы сформулировать выводы. Например:

- «Основная выручка приходится на категорию X»
- «Пик заказов наблюдается по выходным»
- «Товар Y является лидером продаж»

### Шаг 3. Запуск и тестирование

1. Откройте терминал (командную строку) в папке с вашим проектом.
2. Выполните команду:

```bash
streamlit run app.py
```

3. В браузере откроется ваше приложение. Проверьте, что все метрики и графики отображаются корректно. Исправьте возможные ошибки.

### Шаг 4. Финальная проверка

Убедитесь, что ваш код:

- Выполняет все этапы: загрузка, объединение, очистка, расчёт.
- Дашборд содержит все запрошенные блоки.
- Выводы основаны на данных и логически следуют из визуализаций.
